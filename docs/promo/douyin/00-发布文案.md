## 正文文案(可直接复制)

视频里那块「MOD 管理」面板,功能一次看全👇

✅ 集中调参:开关、滑条直接拖,多数几秒生效,不用重启游戏
✅ 生效时机:每项标明「即时 / 读档后 / 重启后」,改完要不要重启一眼知道
✅ 游戏内更新:查新版 → 下载 → 校验,重启游戏就用上新版,不用手动下包覆盖
✅ 冲突体检:已知冲突、补丁碰撞行内图标提示,点开看原因与建议,功能异常不用猜
✅ 全中文界面:参数全是中文人话说明,第三方 MOD 也能自动生成设置页
✅ 禁用 / 排序 / 卸载:第三方一键禁用启用,拖拽排序规避冲突,卸载删干净不残留

🔒 安全兜底:不碰存档、不改游戏本体文件、禁用只改名不删文件、删掉 dll 就完全还原
📦 安装:Full 完整包解压到游戏根目录即用(自带基座);已装 BepInEx 的玩家丢一个 dll 进 plugins 就行
🎮 主菜单 / 游戏内 ESC 出现「MOD 管理」入口,就是装好了
游戏更新后失效属正常,等套件适配新版即可
