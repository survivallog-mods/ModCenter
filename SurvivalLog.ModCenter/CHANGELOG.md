# 更新日志（SurvivalLog.ModCenter / MOD 管理中心）

> 本文件只记本 mod 的更新；套件/安装器版本史见总仓根 CHANGELOG.md。
> 版本号单源：本仓 csproj `<Version>`（作者定义，硬规则 1）。

## v2.0.4（2026-11-07）

### 修复：ModCenter 自身更新无入口（实机反馈缺陷）

- **现象**：检查成功、toast 报"N 个可更新"，但 mod 列表中「面板自身」行没有任何 ↑黄 徽标——
  自更新后端链完整（暂存→selfupdate.flag→壳下一靴替换），却没有 UI 入口可点。
- **根因**：仓库徽标 `RepoIcsOf` 只挂在 `Meta.Mods`（11 个有配置页的套件 mod）行上；自身既
  不在 Meta.Mods、又被 `TpExempt` 排除在第三方列表外，面板里唯一呈现是硬编码的「面板自身」
  行——该行不渲染徽标、伪 guid `__self` 无法路由。仓库页 v3 退役（徽标入口收进行内）时
  自身行被遗漏。
- **修复**：快照 `self` 对象新增可选 `ics` 字段（`SelfInfo.Ics`，`RepoIcsOf` 同源归级：
  Update→↑黄 / Warn→↑黄+⚠橙 / Ok+Kbw→⚠橙 / pending 意图抑制）；面板自身行渲染徽标
  （`SELF_GUID` 真实 GUID 路由）→ 点击进更新确认弹窗 → `MC_UPD('ModCenter')` → 现有自
  更新链。协议向后兼容（空 ics 不输出，老面板无感）。
- **注意**：本版需手动安装一次（旧版没有入口，无法自更新到带入口的版本）；此后（如 v2.0.5
  发版时）自身行 ↑黄 → 一键自更新全链即生效。

## v2.0.3（2026-11-07）

### 检查触发改口径（作者拍板：启动预检替代打开自动查）

- **更新检查**：触发点收敛为两处——① 头部「检查更新」按钮（60 秒冷却不变；启动轮完成后
  60 秒内点击同样吃「检查太频繁」，全失败轮豁免可立即重试）；② **启动 +10s 自动查一轮**
  （面板没开也照跑，结果留 C# 侧，开面板即见徽标/仓库态）。**面板打开不再自动查**——每次
  开面板就发 12 仓 GitHub 请求意义不大（原 15 分钟会话缓存随之退役，仅剩"头 10 秒内手动
  查过则启动轮不重复 fetch"的去重用途）。
- **冲突检测（L2 补丁碰撞）**：同拍挪到启动 +10s 扫一轮（10s 等其他 mod 补丁落账，沿
  DebugPatchScan 探针先例）；面板打开只推最近结果不重扫；汇总弹窗「重新扫描」（MC_SCAN）
  保留兜底晚落账补丁。预检异常时 `PatchScan.Current` 惰性兜底（快照构建现场扫）。
- **不变的**：L1/L3 冲突仍随每次快照构建重算（改配置/开关 mod 即时生效）；GitHub 匿名
  60 次/h 预算内（每靴固定 12 次预检，余量全给手动）；403 限流专门提示口径不变
  （启动轮的 toast 面板未开时静默丢弃，不补弹）。
- 设计口径 D6/§3.1/§6.2.2 同步改写。

## v2.0.2（2026-11-05）

### 三标记体系（作者拍板：标记大瘦身）

- **只留三种行内标记**：⚠红 18px=确定不可用（L1 严重冲突 / 未安装）、⚠橙 15px 小号=
  其余一切告警（L2 补丁碰撞 / L3 同域叠加 / 版本不符）、↑黄 18px=仅有新版本。
  归级口诀：确定坏→红；有新版本→黄；拿不准/有风险→橙；正常→不标。
- **退役**：↓可降级（Downgrade 行零标记，详情页维护区降级按钮同撤；仅 Downgrade+版本
  不符仍可经 ⚠橙 进确认窗）、⊘版本告警独立字形（并入 ⚠橙）、⟳待生效（行内不显，
  底部待生效条保留）、蓝色↑（改黄）。协议 IcInfo 的 G 字段删除（C# 与 panel.js 同步）。
- **未安装不挂标**（实机反馈修正）：主动卸载不是故障，行内锁定开关已表达，红标只留给
  真冲突（首版曾给未安装行挂 ⚠红，实机验证撤回）。
- **可点徽标进点击白名单**（实机修复 v2 老坑）：徽标原为裸 span，宿主页 clickThrough
  白名单（button/input/select/a/[data-interactive]）外的元素实机点击到不了——点徽标
  实际落在行上（MC_CF/MC_UPD 不发）。可点徽标（cf/upd）现带 data-interactive；纯状态
  徽标不进白名单（cursor:default）。
- **颜色拉开**：↑黄 #facc15 亮黄、⚠橙 #fb923c 真橙（原 #fbbf24 偏黄与黄↑难分）。
- **悬停 tip 全部白话**：「有新版本，点击升级」「可能不支持当前游戏版本，点击修复」
  「和其他 mod 撞了（N 处）：X、Y，点击查看」「和同类 mod 叠着用，效果可能乱，点击查看」。

### 降级全面退役（作者拍板：只做 release tag 版本比较）

- **tag ≤ 本地 = 完全静默**：本地版本比仓库最新 release 高（开发机超前构建）时，不再给
  降级态、降级确认弹窗、任何徽标与动作入口——旧版会弹「本地 1.8.4 比远端新…确定要降级
  吗？」引导装回旧版，实机反馈撤除。版本比较本就只取 release 的 update.json（tag）与本地
  dll 版本，无 commit 参与；本次收紧方向判定：仅 tag 大于本地才出 ↑黄。
- **Kbw 版本告警范围收紧**：同版本但 gamekb 不符仍给 ⚠橙（点击「更新到同版本」修复）；
  本地更高行不再参与 gamekb 判定（旧 release 的 gamekb 对超前构建无意义，只会引向变相
  降级）。
- **动作闸加方向校验**：本地比 tag 高时 MC_UPD 直接拒（「本地版本比仓库新，不用动」），
  杜绝任何残留入口变相降级。
- 探针 C 档同步：本地高用例期望翻为 Ok 静默，覆盖断言改为「四态覆盖 + 零降级」，新增
  「同版+基线不匹配（Kbw）」用例。

### Toast 居中 + 生效标识（作者拍板）

- **位置**：右下角 → 面板水平居中、垂直 40%（略偏上不压控件）；15px 加粗主行 + 彩色
  小行；普通 3s / 重启生效类与失败类 4.5s 自动消失。
- **每条 toast 必带生效标识**：⚡已立即生效（绿）/ 🔄重启游戏后生效（橙框）/ 📁读档后
  生效（蓝）/ ⓘ状态播报（灰）/ ✖没成功（红框+原因）。MC_TOAST 协议加 badge 字段
  （now|reboot|reload|info|err），旧事件无 badge 按 info 兼容。
- **文案全部白话化**（C# 21 处 + 面板侧全部）：「已保存：动作加速 · 按键翻页 = 开」
  「动作加速 1.2.3 已就绪 / 重启游戏后自动换上新版」「卸载已备好：X / 重启游戏后移除」
  「已撤销全部待生效操作 / 什么都没变」「检查太频繁（GitHub 限流）/ 等几分钟再试」；
  「加入待生效」「L1/L2/L3」「Remote」等术语从用户可见文案清除。

### 兼容与注意

- 打包布局变化：zip 现含 `BepInEx\plugins\SurvivalLog.ModCenter.dll` +
  `BepInEx\patchers\MCShell.dll` + `README.md`；手动安装需两个 dll 都放到对应目录。
- 从旧版升级（重要）：本版起 `patchers` 组件**换名 `MCShell.dll`**，必须用安装器/完整包
  或手动放置；**只删旧 `MCCleaner.dll` 而不放 `MCShell.dll` 会让启动清理链失效**（更新/
  安装/卸载/停用/排序都不再执行，面板顶部会显示"启动清理组件缺失"告警）。安装器
  `[InstallDelete]` 已自动清理旧件；旧清理器与新逻辑并存会重复执行改名/排序。
  游戏内更新只替换 ModCenter.dll（含清理逻辑），引导壳 MCShell.dll 只有接口签名变更才随安装器更新。
- 旧版 `[Disabled]` 名单退役（无读取方）；第三方停用状态沿用 `[DisabledTp]` marker，
  停用/启用为重启级。
