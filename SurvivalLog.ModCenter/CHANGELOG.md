### 新功能

- **游戏内生命周期**：更新/安装（12 组织仓 GitHub Release：检查、下载、MD5 校验、暂存、
  重启生效）、彻底卸载（dll + cfg + ModCenter 记录；强杀免疫）、第三方停用迁移
  （启动清理器改名为 `.disabled`）、手动加载排序（拖拽 + 键盘替代 + 硬依赖保护）。
- **冲突体检三层**：L1 已知冲突库（红）、L2 运行时补丁碰撞实测（橙）、L3 功能域同域
  （灰）；行内图标 + 点击详情 + 玩家自决，不自动处置。
- **套件仓库页与更新确认链**：12 仓五态、只告警不拦截（版本回退 / gamekb 不符）、
  全部更新（仅 Update 态）、下载进度与失败清理。
- **待生效条**：聚合摘要、撤销全部（含加载顺序）、立即重启（Steam 重拉）。
- **新组件 MCShell**：`BepInEx\patchers\MCShell.dll`（永久冻结的引导壳，单槽基座级；
  清理逻辑已并入 `SurvivalLog.ModCenter.dll` 的 `CleanupRunner`——游戏内更新 ModCenter
  即更新清理逻辑，版本线只有一条）。自卸载为两阶段墓碑（第一次重启写标记，第二次重启
  由壳删除本体）；游戏内自更新由壳在加载前预置替换（一次重启即生效）。

### 修订（v3.1/v3.2，2026-10-30/31 反馈波）

- **图标裸化**（作者审核拍板）：去掉图标周围的圆片描边与底色，改裸 SVG 图标（内嵌
  Lucide 路径离线渲染）——红三角=严重冲突 18px、黄三角=普通告警 15px、蓝/黄圆箭头=
  更新/降级、黄圆斜杠⊘=版本告警（初版用八角带叹号，与冲突三角撞脸，实机反馈后改⊘）、
  琥珀循环=待生效；⇄/◎/字符叹号等文本字形全部退役。
- **冲突详情弹窗去重**：同一 mod 的全部脚本碰撞**合并成一张卡**（此前逐方法、后逐组
  铺卡，who/怎么办每卡全量重复），对方为去重短名（标题不再带 GUID 括注）；单处保留
  方法名、多处给总数；脚本碰撞卡省略「涉及 mod」段。
- **弹窗按钮收敛**：冲突详情只留 关闭 + 去调序（仅碰撞卡时出现）；停用/卸载入口回到
  左列开关与详情页「维护」区，告警弹窗不再摆破坏性按钮。
- **套件内默认兼容**（冲突裁定）：套件↔套件的脚本碰撞与同域叠加不再报告，检测只覆盖
  套件与第三方 mod 之间（未知来源宁可提示）；碰撞汇总计数随之只含已报告组。
- **其他**：排序列表 mod 名换行显示完整（不再截断，悬停有全名）；「检查更新」检查期间
  禁止重复点击，按钮图标旋转提示处理中；游戏版本告警红字改白话（"远端构建依据 gamekb
  …≠ 本地游戏基线" → "这个更新按 {日期} 的游戏版本制作，和你现在的游戏版本不一致，
  可能不兼容"），构建号等开发者信息不再进提示。

### 兼容与注意

- 打包布局变化：zip 现含 `BepInEx\plugins\SurvivalLog.ModCenter.dll` +
  `BepInEx\patchers\MCShell.dll` + `README.md`；手动安装需两个 dll 都放到对应目录。
- 从旧版升级（重要）：本版起 `patchers` 组件**换名 `MCShell.dll`**，必须用安装器/完整包
  或手动放置；**只删旧 `MCCleaner.dll` 而不放 `MCShell.dll` 会让启动清理链失效**（更新/
  安装/卸载/停用/排序都不再执行，面板顶部会显示"启动清理组件缺失"告警）。安装器
  `[InstallDelete]` 已自动清理旧件；旧清理器与新逻辑并存会重复执行改名/排序。
  游戏内更新只替换 ModCenter.dll（含清理逻辑），引导壳 MCShell.dll 只有接口签名变更才随安装器更新。
- 旧版 `[Disabled]` 名单退役（无读取方）；第三方停用状态沿用 `[DisabledTp]` marker，
  停用/启用为重启级。
